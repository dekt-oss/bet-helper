# 베트맨 배당 수집기 (크롬 확장)

본인 크롬 브라우저에서 베트맨 승부식 배당을 주기적으로 읽어 Bet-Helper 앱(`/api/odds/ingest`)으로 보냅니다.
프록시·IP 우회 없이 **사용자 본인 브라우저의 로그인 세션**으로만 동작합니다.

## 설치
1. 크롬 주소창에 `chrome://extensions` → 우상단 **개발자 모드** 켜기.
2. **압축해제된 확장 프로그램을 로드** → 이 `extension/` 폴더 선택.

## 설정 (확장 아이콘 → 설정 열기)
- **앱 ingest URL**: `https://<내앱>/api/odds/ingest`
- **ingest 토큰**: 앱 환경변수 `ODDS_INGEST_TOKEN` 과 같은 값
- **베트맨 gameSlip API URL / 방식 / 본문**:
  1. 베트맨 승부식 페이지를 로그인 상태로 연다.
  2. `F12` → **Network** 탭 → 배당이 로드될 때 뜨는 `gameSlip.do` 요청을 찾는다.
  3. 그 요청의 **Request URL** 을 `slipApiUrl` 에 넣는다.
  4. 요청이 **POST** 면 방식을 POST 로 바꾸고, **Payload/Form Data** 를 본문에 넣는다. GET 이면 비워둔다.
- **수집 주기**: 분 단위(최소 10).

저장하면 앱 도메인 접근 권한을 한 번 요청합니다(전송에 필요). 허용하세요.

## 동작 확인
- 베트맨 **로그인 상태**에서 팝업의 **지금 수집** 클릭 → `✅ N건 저장` 이 뜨면 성공.
- 앱 `/odds`·`/bets` 화면에 배당이 실시간 반영됩니다.
- 이후 설정한 주기마다 자동 수집됩니다(약간의 랜덤 지연 포함).

## 주의
- 베트맨 세션이 만료되면 응답이 비어 실패할 수 있습니다 → 베트맨에 다시 로그인하세요.
- 자동 수집은 베트맨 이용약관 위반 소지가 있습니다. 사용 책임은 사용자에게 있습니다.
- 수집 주체는 사용자 브라우저뿐이며, 서버(앱)는 배당을 직접 가져오지 않습니다.
