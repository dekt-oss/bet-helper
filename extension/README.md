# 베트맨 배당 수집기 (크롬 확장)

본인 크롬 브라우저에서 베트맨 승부식 배당을 **자동 포착**해 Bet-Helper 앱(`/api/odds/ingest`)으로 보냅니다.
프록시·IP 우회 없이 **사용자 본인 브라우저 세션**으로만 동작합니다.
(베트맨은 서버/클라우드 IP를 차단하므로 수집은 반드시 사용자 브라우저에서 일어납니다.)

## 설치 (한 번)
1. 받은 zip 을 PC에 **압축 풀기**.
2. 크롬 주소창 `chrome://extensions` → 우상단 **개발자 모드** 켜기.
3. **압축해제된 확장 프로그램을 로드** → 압축 푼 폴더(안에 `manifest.json` 있는 폴더) 선택.

## 설정 (한 번)
확장 아이콘 → **설정 열기**:
- **앱 ingest URL**: `https://<내앱>/api/odds/ingest`
- **ingest 토큰**: 앱 환경변수 `ODDS_INGEST_TOKEN` 과 같은 값
- **수집 주기**: 기본 360분(6시간), 최소 60분
- 저장 시 앱 도메인 접근 권한을 한 번 요청합니다 → 허용.

## 학습 (한 번)
- 설정 저장 후 **베트맨 승부식 페이지를 평소처럼 한 번 엽니다.**
- 확장이 그 페이지의 배당 요청을 **자동 포착**해 기억하고, 그 즉시 앱에 한 번 저장합니다.
- 팝업에 `✅ 베트맨 요청 학습됨` 이 뜨면 완료. (F12 불필요)

## 이후
- 설정한 주기마다 **자동으로** 학습한 요청을 재실행해 배당을 갱신합니다(약간의 랜덤 지연 포함).
- 앱 `/odds`·`/bets` 화면에 실시간 반영됩니다.
- 팝업 **지금 수집** 으로 즉시 갱신할 수도 있습니다.

## 주의
- 크롬이 실행 중이어야 주기 수집이 돕니다(닫혀 있으면 다음 실행 시 수집).
- 베트맨 세션이 만료되면 응답이 비어 실패할 수 있습니다 → 베트맨에 다시 로그인 후 승부식 페이지를 한 번 여세요.
- 자동 수집은 베트맨 이용약관 위반 소지가 있습니다. 사용 책임은 사용자에게 있습니다.
- 수집 주체는 사용자 브라우저뿐이며, 서버(앱)는 배당을 직접 가져오지 않습니다.
